What an expedition page contains

Each date page is built the same way: the five prompts written out in full, the 100 km gem for each one, how many countries the game accepts for that prompt and how those countries split across the five rarity tiers, plus a short note on what decides the borderline answers. Tier values are the same everywhere — Common 40 km, Uncommon 55 km, Rare 70 km, Elusive 85 km and Farflung 100 km — so five perfect pins make 500 km.

Questions about the archive

Which expedition numbers are covered?

Expedition 47 for 20 November 2026 and Expedition 51 for 24 November 2026 at the moment. Numbering runs one expedition per calendar date, so the expedition number and the date always move together.

Why are some dates missing?

Because the page for that date has not been published yet. Many players search for a round only in the hours after it opens, so the archive fills in as each expedition is written up.

Can I still see a round that has finished?

Not in the game itself — it only shows the current expedition. A finished round's prompts, gems and tier splits survive only on pages like the ones listed above.
